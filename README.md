# 今日复习

iOS 17 / watchOS 10 起的自用 SwiftUI 复习 App。iPhone 用来管理内容，Apple Watch 用来翻卡、勾选当天的复习任务。

## 试用流程

1. 在 iPhone「错题重做」添加一道题。可以输入原题、从照片选择拍好的题图、记录错因。重做后选「独立做对」或「还要再练」。
2. 在错题详情选「为这道题制作手表卡片」，或在「知识卡片」单独添加。手表先显示问题，翻看答案后选「记住了」或「还不熟」。卡片和原题各自计算下次复习日期。
3. 在「复习计划」添加一项任务，设置计划日期和可选的考试日期。到期或逾期任务进入「今日复习」，在手机或手表勾选完成。

连续答对的复习间隔为 1、3、7、14、30 天。选「还不熟」或「还要再练」会将间隔重置为 1 天。考试任务的日期由你填写。

数据保存在设备上。手表通过 Watch Connectivity 接收卡片和任务并回传进度，离线操作先保存在手表上。错题原图留在手机。设备重新连接后由系统调度同步，建议用配对真机验证。

## 构建

在 Windows 上编辑源码。将此目录作为 GitHub 仓库的根目录，并包含 `.github` 目录，Actions 中的 **Build iPhone and Apple Watch** 会生成工程并构建两个目标。当前工作流执行无签名编译检查。

在 Mac 上也可以运行 `brew install xcodegen` 和 `xcodegen generate`，再打开 `ReviewDock.xcodeproj`。真机安装时选择自己的开发团队，并使用自己的唯一 Bundle ID，同时更新 Watch 端 ID 和伴侣 App 标识。TestFlight 分发需另行配置签名、图标及 App Store Connect。
